# 🪖 Battle Simulator 3D

Тактический боевой симулятор, в котором игрок управляет отрядами и наблюдает за развитием сражения в 3D-окружении. Опубликован на Яндекс Играх.

## 📖 Описание

Это один из первых проектов, разработанный в составе команды из двух человек для обучения работе в команде и построения игровых систем. В игре реализована простая тактическая система боя с возможностью расстановки юнитов и запуска симуляции.

## ✨ Особенности
- 3D-окружение с тактическим управлением юнитами
- Основы искусственного интеллекта для боевых сценариев
- Работа с физическим движком Unity
